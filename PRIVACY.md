# Privacy policy

**Effective date:** 2026-10-28

This policy covers Pacelake, a personal, single-user application built by Samuel Fernandes as a data engineering project.

## Who uses it

The application is used only by its owner. It is not offered to other athletes. Do not authorize it with your Intervals.icu account.

## What data it accesses

With the owner's authorization, the application reads from Intervals.icu:

- Activity data, such as type, date, duration, heart rate, and other activity measurements.
- Wellness data, such as sleep, resting heart rate, and other daily measurements.

It requests read-only access. It does not create, change, or delete anything in Intervals.icu.

It also stores workout details the owner enters manually, such as exercises and sets.

## How the data is used

The data is used only to process, analyze, and display the owner's own training and wellness information.

## Where the data is stored

The data is stored in cloud services controlled by the owner, such as cloud storage and a database used by the application. It is not stored in this public repository. Examples in the repository use synthetic data.

## Sharing

The data is not sold, shared with, or disclosed to third parties. The only external parties involved are the infrastructure providers that host the owner's services.

## Retention and deletion

The data is kept while the project is active. The owner can delete it at any time. Detailed retention rules have not been defined yet.

## Revoking access

Access can be revoked at any time from the Intervals.icu settings. After revocation, the application can no longer read new data from Intervals.icu.

## Contact

Questions about this policy can be raised through this repository's issues on GitHub.

## Changes

Changes to this policy are recorded in this repository's history.
